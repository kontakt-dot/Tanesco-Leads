# Bestellreferenz – erfasste Funktionsbereiche

Die bereitgestellte Referenz zeigt eine Bestell-Detailansicht mit einer zentralen Bestellkonfiguration und drei ergänzenden Einstellungsbereichen: **Lieferpausen**, **erweiterte Bestellfilter** und **Lieferanten-Einschränkungen**. Der Hauptbereich enthält eine Bestellhinweis-Notiz, Käuferauswahl, Zuordnung von Lead-Kategorien, Preis- und Provisionssteuerung, Lieferintervall, Zielmenge, Reklamationsausgleich, Priorität, Echtzeit-Lieferung, Bestellzeitraum, Wochentagsfreigaben und Liefergebiet.

Die rechte Spalte enthält einen aktivierbaren Bestellstatus mit chronologischen Ereignissen, eine Synchronisationsinformation samt Schlüssel/Status und einen Supporteinstieg. Die Fluxora-Umsetzung verwendet diese Funktionsstruktur, aber eine eigenständige dunkle Operations-Oberfläche und ausschließlich organisationsgetrennte Daten.
